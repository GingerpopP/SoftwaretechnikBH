# techstack.md – MealPlan

## Projektname
**MealPlan** – Der wöchentliche Menüplaner

---

## Plattform
- **Browser-basiert** (läuft lokal im Browser)
- Optional installierbar als PWA (Progressive Web App)
- Hosting: lokal oder GitHub Pages

---

## Frontend

| Technologie | Zweck |
|---|---|
| HTML5 | Struktur der Anwendung |
| CSS3 | Styling, Responsive Design |
| JavaScript (Vanilla) | Logik, Zufallsgenerator, Einkaufsliste |

---

## Datenspeicherung

| Technologie | Zweck |
|---|---|
| LocalStorage (Browser) | Wochenplan und Rezepte lokal speichern |
| JSON | Rezeptdatenbank als strukturierte Daten |

> Keine Serverdatenbank notwendig. Alle Daten bleiben lokal beim Nutzer (DSGVO-konform, siehe REQ-006).

---

## Optionale Erweiterungen (ab Iteration 2)

| Technologie | Zweck |
|---|---|
| Python / Flask | Falls Backend für Gewichtskontrolle nötig |
| Java / Spring Boot | Alternative Backend-Option |
